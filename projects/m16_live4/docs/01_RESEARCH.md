- **핵심 기능이 무료로 이미 존재한다 — 1차의 "위험"에서 "확인된 조건"으로 격상.** 뱅크샐러드가 카드/계좌 내역 기반 구독 자동 분석을 제공하고(`sha256=8dce1a78ee09d874f7c889e72e7bb6c4db05ea1a6d28afedc7a9bc4bca4cd20c`) 마이데이터로 자동 수집한다(`sha256=d43059535d39e5c60d20ef19f820d4560ca6e66dccf8e74f6b7ccd3c101a63b6`). 무료 대안이 **더 정확하고 더 편하다.** "찾아준다"를 핵심 가치로 둔 설계는 폐기 대상이다.
- **반복 사용 이유의 부재(1차와 동일, 근거로 악화).** 구독 정리는 1회성인데 과금은 월 구독이다. 무료 대안은 마이데이터 연동으로 상시 감시를 무료로 하는데, 이쪽은 CSV 재업로드를 요구한다 — 감시 가치 경쟁에서 구조적으로 진다.
- **가격 앵커 붕괴.** 평생 2.99달러 사례와 "월 구독 아닌 일회성 결제" 포지셔닝이 이미 정착되어 있다(`sha256=d929759b7b2490ccadcc47714d1d3beb59253b3f39461aeefcf5c88a53d2bd5a`, `sha256=8b5eb96eac7053dbf55327df0a33e6017cc88cbdddc71054077703a4b57209d4`). "구독 추적기" 카테고리에서 월 9,900원은 성립하지 않는다.

### High

- **가맹점명 매칭 커버리지 — 근거 0건인데 제품 품질을 결정한다.** 검증되지 않은 최대 기술 변수가 그대로 남았다. 커버리지가 낮으면 신뢰가 즉시 붕괴한다. **실측 없이 구현 착수하면 이 리스크가 그대로 코드가 된다.**
- **개인정보/금융정보 취급 리스크(1차와 동일).** 서버 저장 설계는 1인 운영자가 감당할 부담이 아니다. 로컬 처리 설계로 회피 권장.
- **잘못된 해지 권고로 인한 실질 피해(1차와 동일).** 사용자 확인을 강제하는 UX 필수.
- **타겟 도달 경로 부재(1차와 동일).** "월 SaaS 30만 원 쓰는 국내 1인 사업자"가 모인 채널이 불명확하다. 근거에서도 해소되지 않았다.
- **"무료 대안이 중복을 못 짚는다"가 미확인이다.** 이 아이디어의 마지막 방어선인데, 스니펫은 기능 목록이지 부재 증명이 아니다. 뱅크샐러드가 중복 지적을 이미 하고 있다면 남는 차별점은 경비 처리뿐이다.

### Medium

- **CSV 업로드 마찰(1차와 동일, 근거로 악화).** 무료 대안이 마이데이터 자동 연동인 것이 확인됐으므로, 수동 업로드의 상대적 마찰이 더 크게 보인다.
- **성과 과금 모델의 운영 부하(1차와 동일).** 초기 배제.
- **경쟁 진입 용이성(1차와 동일).** alias 사전 외 해자 없음.
- **국내 SaaS 결제 문자열 파편화(1차와 동일, 여전히 미확인).**
- **해외 저가 앱의 국내 진입.** 스토어에 한국어 페이지가 이미 있다(`sha256=193277ab00e40bb65850773d517cb911b6868a0b964f9d34b0e09bbbce0e7106`). 수동 입력 모델이라 직접 경쟁은 아니지만 가격 인식을 계속 눌러 놓는다.

### Low

- 환율 변동으로 인한 해외 SaaS 원화 금액 불일치 — 허용 오차로 처리 가능.
- 연간 결제 구독은 13개월치 명세가 없으면 탐지 불가 — 업로드 기간 안내로 완화.
- 브랜드/상표 리스크(서비스명 나열, 해지 유도).
- **앱스토어 구독은 카드 명세에 Apple/Google로만 찍혀 서비스 역추적이 불가할 수 있다.** 앱스토어 구독은 휴대폰 설정에서 해지한다는 안내가 존재하는 것으로 보아(`sha256=53796638eb9be2f239b2ea44cd6675d0b549acce9c6b84c3e17a653843f4907a`) 결제 주체가 스토어로 묶인다. 이 경우 CSV만으로는 "Apple 12,000원"이 무슨 구독인지 알 수 없다 — **Low에 두지만 실측(Next Action 2)에서 비율이 크면 High로 올려야 한다.**
