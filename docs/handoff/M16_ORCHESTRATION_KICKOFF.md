### 2.1 필수 작업 (이것 없이는 실사용 불가)

우선순위 순. **각 항목은 대장에 근거와 file:line이 있다.**

   **수정 전에 재현이 먼저다.** v3 실행층 실사용 전 필수.
4. **live 4단계 계측** — `dev-handoff`는 workflow가 아니라 `task_prompt` 단계라(F3) **파이프라인
   경로로만** 닿는다. `P1`은 단독 `run`이라 거기 못 갔다. `B-47`이 닫힌 뒤에 시도하라 — 안 그러면

## 4. 절대 하지 말 것

- **`--delete-branch`로 스택 PR 머지** — 뒤 PR이 자동 close된다.
- **스위트를 겹쳐 돌리기** — acceptance가 244/28로 무너지고 그것을 회귀로 오인한다(`C-151`).
  `test:core`·`test:exec`·`acceptance`를 **하나씩** 돌려라.
- **아이디어 문서에 판정 기준을 써 넣기** — `B-51`이 실증한 게이트 우회다. 제약 제시("월 30만 원이면
  성공으로 본다")는 정당하고 결론 지시("이 리스크는 무시하라")는 조작이다. 사용자 선호를 전달할 때는
  **"이 절은 CEO의 판정 기준을 대체하지 않는다 · 어느 결론도 선택할 수 있다"** 를 먼저 적어라.
- **서브에이전트에게 worktree에서 `node_modules`를 심볼릭 링크하게 하기** — worktree 정리가 링크
  대상(메인 레포의 진짜 `node_modules`)까지 지운다. `npm ci`로 복구해야 한다.
- **`git clean -fd`** — M14의 live 7 run 증거가 그렇게 사라졌다. `projects/_t_preflight/`는 커밋돼
  있지만 새 live 산출물은 untracked다.

## 5. 비싸게 배운 함정 (M14 22개 + M15 넷)

M14 §4의 22개와 M15 킥오프의 23~25는 그대로 유효하다. 추가:

26. **스위트를 겹쳐 돌리면 회귀를 만들어 낸다.** acceptance 단독 272/0이 겹치면 244/28이다.
    `suite-lock`은 `npm test` 경로만 지킨다 — `npm run test:core`·`npm run acceptance` **직접 호출에는
    보호가 없다.** M15가 그 실수를 했고 28건을 회귀로 오인할 뻔했다.
27. **문자열을 고칠 때도 형제를 grep하라.** 코드는 "모든 호출자를 grep"하고 고치면서 **안내 문자열은
    그러지 않았다.** `driftMessage()`는 *"drift 거부 문장은 한 곳에서 만든다"* 는 주석을 달고 있었는데
    M15가 고친 것은 **다른 쪽**이었다. 이 한 가지 습관 차이로 거짓 안내 **3건을 새로 만들었다**(`B-58`).
    → 이제 `src/core/guidance.test.ts`가 명령 문자열과 `run_state.json` writer를 **전수로** 잰다.
28. **골든은 변경 감지기다.** 스키마를 늘리면 골든이 걸리는데, **말없이 고치면 감지기가 죽는다.**
    바꿀 때마다 테스트 주석에 "왜 늘었나 · 왜 이 자리인가"를 적어라.
29. **계약이 지시하는 모양이 그 계약의 검사를 무력화할 수 있다.** a11y 검사가 `semantic.color`만
    훑는데 **같은 프롬프트가** 다크 모드를 `semantic.light`/`dark`로 분기하라고 지시했다 — 지시를
    따르면 검사가 0회 돈다(`C-157`). **계약을 배선하기 전에 그 계약이 실제로 재는지부터 확인하라.**
    그리고 **배선하자 test provider가 곧바로 red가 되면 그것이 "한 번도 안 돌았다"는 증거다** —
    그럴 때 고칠 것은 계약이 아니라 test provider다.

## 6. 작업 방식

- 계획은 **Fable 설계 세션 → Codex 계획 리뷰(영어) → Opus 구현(격리 worktree)**.
- 비평은 **Codex**(`gpt-5.6-sol` / 값싼 검증은 `gpt-5.5`). `codex exec -s read-only -m <model> "$(cat <파일>)" < /dev/null`
  — **stdin 닫기 필수**, 인용부호가 든 프롬프트는 **파일로 넘기고 크기를 확인한 뒤** 넘겨라(함정 23).
- **Codex 프롬프트·서브에이전트 지시는 영어, 사용자 보고와 문서는 한글**(실측 1.46배).
- finding은 **실물 검증 후에만** 리비전 발행. 코드만 읽은 것은 그렇게 표시하라.
- PR은 코드 **1000~1200줄** 단위로 쪼갠다. 스택은 8개를 넘기지 마라.
- 보고는 **간결하게**, 끝에 **진행률(%) · 필수 작업 · 개선 작업**을 적는다.
